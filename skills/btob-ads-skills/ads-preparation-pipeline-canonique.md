# ads-preparation-pipeline-canonique

**Pack** : [Pack BtoB Ads Skills](https://markentiq.com/l/gh-pack-ads)

Normalise n'importe quelle source de pipeline (export CRM, MCP CRM, base Airtable, CSV tenu à la main) vers le schéma canonique qui permet de piloter les campagnes au CAC et au coût par opportunité. Utiliser quand l'utilisateur veut brancher son pipeline sur le pilotage publicitaire, normaliser ses données de leads et d'opportunités, mapper les stages de son CRM, préparer un export pour la lecture pipeline, ou quand ses sources de données pipeline sont hétérogènes. Ne pas utiliser pour spécifier le tracking des campagnes (ads-preparation-plan-de-mesure) ni pour analyser les résultats (ads-pilotage-lecture-pipeline).
