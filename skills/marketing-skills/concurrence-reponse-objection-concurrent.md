# concurrence-reponse-objection-concurrent

**Pack** : [Pack Marketing Skills](https://markentiq.com/l/gh-pack-marketing)

Construit des réponses prêtes à prononcer quand un prospect compare avec un concurrent ou cite ses arguments. Utiliser quand l'utilisateur demande quoi répondre quand un prospect mentionne un concurrent, comment réagir à « on regarde aussi X », une réponse à une comparaison de prix avec un rival, un contre-argument face à une feature concurrente, ou un script pour un deal disputé. Ne pas utiliser pour les objections génériques prix, budget ou statu quo (vente-reponses-aux-objections) ni pour produire la fiche concurrent complète (concurrence-battlecard).

## Obtenir la Skill

La Skill complète (instructions, gabarits, contrôles) est dans le Pack Marketing Skills, en accès libre sur [markentiq.com](https://markentiq.com/l/gh-pack-marketing) : le pack se reçoit contre une adresse email. Ce dépôt n'en contient que la fiche.
