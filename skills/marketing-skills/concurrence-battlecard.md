# concurrence-battlecard

**Pack** : [Pack Marketing Skills](https://markentiq.com/l/gh-pack-marketing)

Génère une battlecard complète et actionnable sur un concurrent en vingt minutes. Utiliser quand l'utilisateur demande une fiche concurrent, une battlecard, un argumentaire contre un concurrent, comment se positionner face à un rival, quoi répondre quand un prospect compare avec un concurrent, ou une mise à jour de fiche concurrentielle pour les ventes. Ne pas utiliser pour redéfinir le positionnement de fond (Pack Positioning) ni pour la veille continue (Skill concurrence-veille-concurrentielle).

## Obtenir la Skill

La Skill complète (instructions, gabarits, contrôles) est dans le Pack Marketing Skills, en accès libre sur [markentiq.com](https://markentiq.com/l/gh-pack-marketing) : le pack se reçoit contre une adresse email. Ce dépôt n'en contient que la fiche.
