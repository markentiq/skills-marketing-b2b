# vente-presentation-commerciale

**Pack** : [Pack Marketing Skills](https://markentiq.com/l/gh-pack-marketing)

Construit une présentation commerciale personnalisée qui raconte le problème du prospect avant le produit. Utiliser quand l'utilisateur demande un deck de vente, un support de démo ou de soutenance, une présentation pour un rendez-vous client, la structure d'un pitch commercial, comment personnaliser sa présentation pour un compte, ou un support pour un comité de décision. Ne pas utiliser pour le premier rendez-vous de découverte (vente-preparation-rdv-decouverte) ni pour le document de justification économique (vente-business-case-executif).
