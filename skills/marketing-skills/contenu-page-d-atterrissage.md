# contenu-page-d-atterrissage

**Pack** : [Pack Marketing Skills](https://markentiq.com/l/gh-pack-marketing)

Rédige une page d'atterrissage complète orientée conversion, du titre au CTA, avec structure et preuves. Utiliser quand l'utilisateur demande une landing page, une page de destination pour une campagne, une page produit ou offre, un texte de page qui convertit, une page pour un webinaire ou un aimant à leads, ou d'améliorer une page qui ne convertit pas. Ne pas utiliser pour une page pensée d'abord pour le classement dans les moteurs de recherche (Pack SEO Skills) ni pour une page comparative face à un concurrent (concurrence-page-comparative).
