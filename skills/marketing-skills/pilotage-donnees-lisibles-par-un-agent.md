# pilotage-donnees-lisibles-par-un-agent

**Pack** : [Pack Marketing Skills](https://markentiq.com/l/gh-pack-marketing)

Rend les données marketing d'une PME lisibles par un agent IA sans entrepôt de données lourd : inventaire des sources, choix lecture directe ou copie datée pour chacune, catalogue des tables avec leur date, règle de trace et test de lecture. Utiliser quand l'utilisateur demande comment brancher son agent IA sur ses données marketing, de donner à Claude accès à GA4, Search Console, ses régies ou son CRM, de centraliser ses exports marketing, pourquoi l'agent cite des chiffres périmés, un tableau de bord lisible par une IA, ou s'il faut un entrepôt de données. Ne pas utiliser pour produire le rapport mensuel (pilotage-synthese-pipeline-mensuelle) ni pour lire une source en profondeur (technique-lecture-ga4, Pack SEO Skills).
