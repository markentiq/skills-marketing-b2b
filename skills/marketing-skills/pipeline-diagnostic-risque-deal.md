# pipeline-diagnostic-risque-deal

**Pack** : [Pack Marketing Skills](https://markentiq.com/l/gh-pack-marketing)

Analyse en profondeur une opportunité commerciale pour identifier ses risques réels, ce qui manque pour gagner et le plan de consolidation. Utiliser quand l'utilisateur demande pourquoi un deal inquiète, une revue de deal, un diagnostic d'opportunité, si un deal va vraiment se signer, ce qui manque pour gagner une affaire, une analyse avant le forecast, ou un avis avant d'investir plus sur un compte. Ne pas utiliser pour prioriser l'ensemble du pipeline (pipeline-priorisation-pipeline) ni pour relancer un deal déjà silencieux (pipeline-relance-opportunite-dormante).
