# pilotage-plan-de-tests-ab

**Pack** : [Pack Marketing Skills](https://markentiq.com/l/gh-pack-marketing)

Construit un plan de tests A/B rigoureux et priorisé : hypothèses, variantes, tailles d'échantillon réalistes et règles de décision. Utiliser quand l'utilisateur demande un plan de tests A/B, quoi tester en priorité sur ses pages ou emails, comment structurer une expérimentation, si son test est significatif, un backlog d'optimisation, ou pourquoi ses tests ne concluent jamais rien. Ne pas utiliser pour localiser d'abord les fuites du funnel (pilotage-audit-de-funnel) ni pour rédiger les variantes créatives elles-mêmes (contenu-publicites-multi-angles, contenu-page-d-atterrissage).
