# vente-plan-d-action-mutuel

**Pack** : [Pack Marketing Skills](https://markentiq.com/l/gh-pack-marketing)

Construit un plan d'action mutuel qui structure le chemin vers la signature avec le prospect : étapes, responsabilités des deux parties, dates et jalons de décision. Utiliser quand l'utilisateur demande un mutual action plan, un rétroplanning de deal, comment cadrer les prochaines étapes avec un prospect, un document partagé pour piloter un cycle de vente, comment éviter qu'un deal s'enlise après une bonne démo, ou comment tester le sérieux d'un prospect. Ne pas utiliser pour relancer un deal déjà silencieux (pipeline-relance-opportunite-dormante) ni pour évaluer les risques d'un deal (pipeline-diagnostic-risque-deal).
