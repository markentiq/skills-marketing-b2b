# contenu-relecture-tics-ia, une Skill complète

Cette Skill est publiée ici en entier, pour juger une Skill MarkenTIQ sur pièce. Elle relit un texte en français et repère les tics de l'écriture générée par l'IA, puis propose une correction sans ajouter de fait. Les 79 autres Skills sont décrites dans l'index ; leur contenu est dans les packs.

Version : Pack Marketing Skills v1.13.1. Le fichier `SKILL.md` est identique à celui du pack.

## L'utiliser

- **Avec ChatGPT, Claude ou Vibe** : collez le contenu de `SKILL.md` dans la conversation, puis le texte à relire.
- **Avec Claude Code ou Cowork** : copiez le dossier `contenu-relecture-tics-ia` dans `~/.claude/skills/` ; la Skill se déclenche quand vous demandez de relire un texte écrit avec l'IA.

La Skill cite `04_BUSINESS_CONTEXT.md` pour les interdits propres à votre marque. Ce fichier est facultatif : il vient avec le [Pack Marketing Skills](https://markentiq.com/l/gh-pack-marketing).
